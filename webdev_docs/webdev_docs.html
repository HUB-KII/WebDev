HTML Basics

HTML provides the structure of a web page.

Elements are written using opening and closing tags in most cases.

<h1>Hello World</h1>
  • HTML defines page structure.
  • Elements can contain other elements.
CSS Basics

CSS controls the appearance of HTML elements.

You can use CSS to change colors, spacing, fonts, and layouts.

color: blue;
  • CSS controls presentation.
  • Rules contain selectors and declarations.
Selectors

Selectors determine which HTML elements a CSS rule targets.

Class and attribute selectors are useful for targeting specific elements.

.container { width: 100%; }
  • Element selectors target HTML tags.
  • Class selectors begin with a period.
Flexbox

Flexbox is a CSS layout system designed for one-dimensional layouts.

It makes it easier to arrange elements in rows or columns.

display: flex;
  • Use flex-direction to control the main direction.
  • Use justify-content to distribute items.
Responsive Design

Responsive design allows websites to adapt to different screen sizes.

Media queries can apply different CSS rules depending on the viewport.

@media (min-width: 768px) { }
  • Mobile-first design starts with smaller screens.
  • Media queries can enhance layouts for larger screens.
